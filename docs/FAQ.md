# Frequently asked questions

## Is this a WordPress plugin or a ready-to-install theme?

No. Abdoul WP Landing Architect is a **private AI Agent Skill** for creating structured planning output, not a WordPress plugin or a theme.

## Can I run the Skill from this GitHub repository?

No. This repository only includes public documentation and fictional examples. The proprietary `SKILL.md`, implementation guidance, supporting scripts and private distribution package are not included.

## Does it create a published landing page automatically?

No. It generates a **blueprint**: sections, suggested copy, UX rationale, responsive recommendations, and a WordPress/Gutenberg implementation map. A developer or builder still needs to implement and test the site.

## Does it support forms, booking, or payment processing?

It can identify these needs and explain the integration work involved. Gutenberg core content blocks alone do not provide complete public form processing, live scheduling or card checkout.

## Is WCAG 2.2 AA compliance guaranteed?

No. The Skill can recommend accessibility checks, but conformance requires evaluation of the implemented site and its relevant user flows.

## Is it available to purchase or install?

No public commercial offer is announced in this preview. Availability depends on publisher eligibility, distribution arrangements and the intended license.

## Which languages are supported?

The verified blueprint workflow and current public copy are **English-first**. Other output languages are not claimed to be tested or supported in the current preview.

## May I reuse these documents or the private Skill?

The private Skill is proprietary and not included here. No license granting reuse of the private implementation is announced. Contact the owner through an approved public channel if one is supplied in the future.
