# Security and responsible disclosure

This repository contains **public documentation only**. It is not a WordPress plugin, production deployment, runnable Skill package, or a place to store private data.

## Never post publicly

- API keys, passwords, tokens or configuration secrets.
- Private `SKILL.md` implementation files or proprietary scripts.
- Real customer briefs, contact lists, or production-site credentials.
- Sensitive security findings about a real website.

## Reporting concerns

For issues about public documentation (typos, broken links, inaccurate descriptions), you may use repository issues **without posting sensitive information**. For sensitive concerns, use GitHub's private vulnerability reporting feature **if enabled by the maintainer**, or request a private contact channel without disclosing the details publicly.

## Security claims

Local checks of a private Skill's file structure do not establish that any deployed system is secure. No deployed WordPress, checkout or booking system is part of this repository.
