# Abdoul WP Landing Architect — public project preview (v0.2.0)

A private Agent Skill to prepare evidence-aware, mobile-first WordPress/Gutenberg landing-page blueprints. Focuses on UX rationale, English page copy, accessibility planning, realistic WordPress implementation boundaries, and honest publication blockers.

## Illustrative uses
- Technical B2B purchasing / quote inquiry architecture
- Local service page with appointment inquiries
- Conflict handling when a client requests unsupported booking, payment, or unverifiable marketing claims

## Not included in this preview
The private `SKILL.md`, implementation references, tools, and complete commercial Skill are **not included**. This public preview alone cannot run as an Agent Skill. All demo data are fictional.

## Current maturity
The original v0.1.0 was exercised in local Codex tests. The private v0.2.0 package passed offline structural and release-regression checks, and a **single limited Codex integration smoke test** reported successful loading of `version: 0.2.0` and correct handling of a fictional client brief with conflicting claims. These are local checks and an agent self-assessment, not an independent quality audit. **No live WordPress page was built.** Browser behavior, email delivery, payments, scheduling, WCAG conformance, and marketplace acceptance have **not** been tested or certified. The fictional client page was correctly designated **NO-GO** for publication due to missing contact details and incompatible requirements.
